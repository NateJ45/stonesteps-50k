# Security policy

## Supported versions

Only the `main` branch, which is what runs at https://stonesteps50k.com, is supported.

## Reporting a vulnerability

Please report security issues privately by email to nathan@nixoncreativestudio.com. Do not open a public issue or pull request for a suspected vulnerability.

Include what you found, where, and the steps to reproduce it. You will get a reply, and a fix will be made on `main` once the issue is confirmed.
